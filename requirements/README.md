# Requirements Files

This directory contains all Python package requirements for the eDNA Biodiversity Assessment System.

## Files

- **requirements.txt** - Main requirements file (all dependencies)
- **requirements_core.txt** - Core dependencies for basic functionality
- **requirements_windows.txt** - Windows-specific dependencies
- **requirements_report_management.txt** - Report management system dependencies

## Installation

### Full Installation
```bash
pip install -r requirements.txt
```

### Core Only
```bash
pip install -r requirements_core.txt
```

### Windows-Specific
```bash
pip install -r requirements_windows.txt
```

### Report Management Add-on
```bash
pip install -r requirements_report_management.txt
```
