Avalanche eDNA CI/CD & GitHub Pages Architecture

This deployment is powered by a cross-platform Jenkins pipeline running locally as a Windows Service at http://localhost:8081, interacting with Git origin and syncing production artifacts to GitHub Pages.

Jenkins Master Port 8081 • Declarative Pipeline
➔
Mock CI/CD Runner scripts/ci/jenkins_runner.py
➔
Test & Packaging JUnit XML • Docker Manifest
➔
GitHub Pages (gh-pages) Static CDN Deployment
How to Trigger Directly from Terminal or Jenkins:
# Run complete mock pipeline locally:
python scripts/ci/jenkins_runner.py test --mode mock
python scripts/ci/jenkins_runner.py deploy --env staging --mode mock

# Deploy UI to GitHub Pages via Jenkins runner:
python scripts/ci/jenkins_runner.py deploy-gh-pages
